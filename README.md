# hold-trauma-informed-interface
A trauma-informed digital interface that helps people navigate high-stress institutional interactions through communication support, grounding tools, accessibility features, and survivor-centered resources
Hold — Trauma-Informed Communication Interface

Hold is a mobile-style prototype designed to support survivors navigating stressful interactions with institutions such as healthcare, law enforcement, education, and social services.

Technologies
p5.js
JavaScript
HTML
CSS
Features
Before / During / After support
Communication prompts
Grounding tools
Rights and reporting information
Accessibility support
Read-aloud functionality

My Role: Designed and developed the prototype as part of my MFA in Design and Technology at Parsons School of Design.
